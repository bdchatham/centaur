- (direction) Express mode, headless. Brief: add GET /api/version to centaur-api-server returning JSON {version, git_commit}; commit/version embedded at build time; follow healthz conventions; proven by a route test asserting both fields are non-empty strings; no spec_checkpoint.
- (capability) CAP-1: GET /api/version returns 200 JSON with non-empty string fields version (cargo package version) and git_commit
- (capability) CAP-2: version and git_commit are fixed at build time; a build with no resolvable commit reports 'unknown', never empty and never a failed build
- (capability) CAP-3: endpoint is reachable without credentials and before the runtime is ready, like /healthz
- (decision) Public route registered beside /healthz in the unauthenticated Router (routes.rs), not in the protected group: no Capability/route_access entry needed, and deploy tooling can poll it. Build info is not sensitive. Recorded as assumption.
- (constraint) Code evidence: healthz/readyz/metrics are registered on the outer Router in routes.rs build_router_with_app_state; existing public-route test lists them in lib.rs. Crate has no build.rs; mcp.rs already uses env!(CARGO_PKG_VERSION).
- (constraint) Commit resolution order in a new build.rs: env CENTAUR_GIT_COMMIT, then 'git rev-parse HEAD', then 'unknown'. Docker build context has no .git (services/api-rs/Dockerfile copies only crates/ and services/api-rs/), so the image build must pass the commit as a build arg.
- (constraint) Proof by a new test file under crates/centaur-api-server/tests using only existing public items (build_router_with_app_state, AppState::unready, ApiAuthConfig); no database; fails before the change with 404 on the missing route.
- (decision) Single story: route, build.rs and Dockerfile/Justfile plumbing ship together; splitting leaves a route without commit data or untestable plumbing.
- (question) Should .github/workflows/publish-images.yml pass the commit as a build arg to the api-rs image? Not in scope here (CI change); until done, published images report git_commit 'unknown' unless built via the Justfile.
- (question) Full 40-char SHA or short SHA? Spec assumes full SHA.
- (question) Should the route be auth-gated instead of public? Spec assumes public.
