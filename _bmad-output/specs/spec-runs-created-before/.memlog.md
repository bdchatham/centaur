- (note) Code read: created_after already exists end to end. types.rs ListWorkflowRunsQuery has created_after: Option<String>; routes.rs list_workflow_runs parses state then created_after (Rfc3339, 400 naming created_after) before workflow_runtime(&state); WorkflowRuntime::list_runs_by_state(limit, workflow_name, state, created_after) fans out over 4 queues (workflow, slack-live, etl, etl-backfill) calling list_runs_for_queue, whose SQL has 'and ($4::timestamptz is null or t.enqueue_at > $4)' before 'order by t.enqueue_at desc, t.task_id desc limit'; created_at = t.enqueue_at; results merged, sorted, truncated to limit. list_runs (no filters) also calls list_runs_by_state. Existing tests/runs_created_after_http.rs is the pattern for HTTP-only tests.
- (capability) CAP-1: a client lists only runs whose created_at is strictly before ?created_before (RFC 3339), newest first.
- (capability) CAP-2: created_before composes with limit, workflow_name, state and created_after; limit counts matching runs; with both bounds the runs lie in the open interval (created_after, created_before).
- (capability) CAP-3: a created_before value that is not valid RFC 3339 is HTTP 400 naming created_before and RFC 3339; absent param behaves as today.
- (constraint) Strictly before: a run created exactly at the bound is excluded; offsets compare as instants (10:00:00+02:00 equals 08:00:00Z).
- (constraint) Bound applied in each queue's SQL (t.enqueue_at < bound) before limit, like created_after and state, so limit counts matching runs across all four queues.
- (constraint) Parse created_before before the workflow runtime lookup so an invalid value is a 400 whatever runtime availability; gives DB-free red tests. Reuse the created_after parsing rather than duplicate it is a dev choice.
- (constraint) Additive only: response shape, ordering, default limit unchanged; no migration; no new index.
- (constraint) Proof via HTTP route only: new test file under centaur-api-server/tests using no symbol this work adds, so it compiles before the change and fails because created_before is ignored (serde drops unknown query keys). - (assumption) A bound earlier than every run returns an empty runs list with HTTP 200.
